# Angle: Interpretational Database

**Best for:** HN Phase 1, DEV.to main article, philosophy-first threads  
**Hook:** Memory, not archive. Meaning at read time.

## One paragraph

INDB is an **Interpretational Database** — not a row store. Events are observations; meaning is produced by Prism, Echo, Instinct, Deduction when you query. Ingest is Inhale (chaos accepted); Fusion is Exhale (noise compressed); signed core is Axiom. Category we own: interpretational-database, not time-series, not graph DB.

---

## Differentiators vs classic DB

| Classic DB | INDB |
|------------|------|
| Schema = meaning | Tokens + location; meaning at query |
| UPDATE overwrites | Fusion + paradox preserves contradiction |
| Trust = ACL | Trust = reputation² + Grain + signatures |
| Backup = copy | Recovery = key_id + signed export verify |
